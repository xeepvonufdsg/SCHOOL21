## Chapter II

### Android NDK

Android NDK (Native Development Kit) — это набор инструментов, предоставляемых разработчикам для создания своих Android-приложений на языках программирования C и C++. Он позволяет интегрировать нативный код (код на C/C++) в приложения, что полезно для улучшения производительности, доступа к аппаратному обеспечению и портирования существующего кода на платформу Android. Например, его используют при разработке игр со сложной графикой.

Android NDK позволяет интегрировать вызов C++ кода в Java/Kotlin. Для этого существует Java Native Interface (JNI). JNI предоставляет механизмы для вызова функций нативного кода из кода на Java/Kotlin и наоборот. Это означает, что ты можешь создавать функции на C/C++, которые могут быть вызваны из твоего кода на Java/Kotlin.

Более подробный разбор NDK [на сайте Android](./materials/references.md#android-ndk).

### RenderEffect

[RenderEffect](./materials/references.md#rendereffect) — это класс добавленный в Android 11 (SDK 31) для улучшения логики обработки применения эффектов к различным View. RenderEffect — это мощный инструмент для применения визуальных эффектов, таких как размытие, наложение цвета при отрисовке. Такие эффекты можно применить как к высокоуровневым представлениям (View, Canvas), так и к более низким (RenderNode).

По сути, RenderEffect пришел на замену части функционала RenderScript API, который с Android 11 изменил статус на deprecated. Главным преимуществом после добавления RenderEffect стало упрощение для разработчиков работы с применением эффектов без глубокого погружения в их реализацию.

### AGSL

Android Graphics Shading Language (AGSL) — это язык для работы с графической системой Android, добавленный в Android 13. AGSL можно рассматривать, как производную от языка шейдеров OpenGL — GLSL. Несмотря на почти идентичность в синтаксисе, AGSL адаптирован специально для Android, обеспечивая более тесную интеграцию и эффективное взаимодействие с такими классами, как Canvas и View.

AGSL позволяет разработчикам создавать различные сложные визуальные эффекты, такие как тени и размытие, при этом код, необходимый для их реализации, остается относительно простым и понятным.

Более подробно про AGSL и кейсы его применения посмотри в [документации](./materials/references.md#agsl).

## Chapter III

# Проект: Android NDK и работа с графикой на низком уровне

В этом проекте ты создашь приложение, которое познакомит тебя с Android NDK и обработкой изображений при помощи встроенных решений. Твоя задача — сделать приложение, которое сможет кодировать-декодировать изображения и применять к ним различные эффекты — блюр, негатив.

# Описание и требования

- Код программы должен находиться в папке src и не противоречить требованиям ниже.
- В качестве рекомендаций по дизайну можешь использовать [Material 3](./materials/references.md#%D0%B4%D0%B8%D0%B7%D0%B0%D0%B9%D0%BD-%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC%D0%B0-material-3).
- Дизайн приложения должен быть интуитивно понятным.
- Для сохранения данных при повороте устройства используй преимущества ViewModel.
- Обеспечь взаимодействие с View экранов при помощи ViewBinding.

**Для реализации мобильного приложения нужно использовать:**

- Android Studio 2023.1.1;
- Kotlin 1.9.0;
- Android SDK 34;
- Gradle 8.2 (управление зависимостями);
- Material 3 (создание пользовательского интерфейса).

# Задачи

Создай проект для мобильного приложения в Android Studio.

### Глава 1. Создание и использование модуля Android NDK

### Задание 0. Создание проекта

- Выбери в Android Studio File->New->New Project...
- Выбери Phone and Tablet и Empty Views Activity.
- Введи имя приложения — Unit N (где N — номер блока).
- Выбери язык разработки — Kotlin.
- Выбери язык конфигурации сборки — Kotlin DSL.
- Код программы должен находиться в папке src.
- Добавь поддержку viewBinding в buildFeatures gradle.

### Задание 1. Кодирование и декодирование с Android NDK

1. Скачай Android NDK, если у тебя его нет, во вкладке File->Project Structure.
2. Создай модуль Android Native Library с названием imageconverter, в котором будет описано кодирование и декодирование Base64 формата.
3. Создай файл внутри каталога imageconverter/src/main/cpp base\_64.h (заголовочный файл с объявлением функций).
   Пример объявления функций для кодирования и декодирования:

   ```
   #ifndef _BASE_64_H_
   #define _BASE_64_H_

   #include <vector>
   #include <string>
   typedef unsigned char BYTE;

   std::string encode(std::vector<BYTE> buf)
   std::vector<BYTE> decode(std::string encodedString)

   #endif
   ```
4. Создай base\_64.cpp, в котором будет определение (реализация) функций заголовочного файла base\_64.h.
5. Добавь base\_64.h и base\_64.cpp в CMakeLists.txt.
6. Реализуй функцию кодирования `encode` в base\_64.cpp. Входным параметром в функцию должен быть std::vector (массив байтов из Bitmap), результат — std::string. Спецификацию формата Base64 можешь посмотреть [здесь](./materials/references.md#base64).
7. Реализуй функцию декодирования `decode` в base\_64.cpp. Входным параметром в функцию должен быть std::string, результат — std::vector (массив байтов для Bitmap).
8. Объяви JNI функции со стороны C++ в imageconverter.cpp. Эти функции будут вызваться из твоего Kotlin-кода, и их можно называть JNI (Java Native Interface) функциями. В C++ обертках должны вызываться созданные функции из base\_64.cpp.
9. Добавь в Kotlin класс NativeLib объявление C++ функций. Для это воспользуйся ключевым словом external. Объяви `external fun` — `encode`, `decode` с входными параметрами и возвращаемыми значениями для кодирования/декодирования изображения.
10. Объяви модуль imageconverter в качестве зависимости app.
11. Создай пользовательский интерфейс экрана MainActivity в модуле app, который должен содержать:

    - Button для выбора изображения из галереи (воспользуйся [PhotoPicker](./materials/references.md#photopicker));
    - ImageView для отображения выбранного изображения;
    - TextView для отображения закодированной строки на месте ImageView;
    - Button для замены выбранного изображения в ImageView на TextView для закодированной строки и наоборот при помощи созданного модуля c Android NDK.

### Глава 2. Обработка Bitmap

### Задание 2. Попиксельная инверсия цветов Bitmap

1. Создай файл BitmapExtensions и в нем функцию-расширение для Bitmap `applyPixelNegative` с возвращаемым типом Bitmap — обработанное изображение с применением эффекта негатива (инверсия цветов).
2. Каждый пиксель в Bitmap имеет цвет в формате RGB (Red, Green, Blue). Для применения инверсии цветов тебе нужно для каждого пикселя изменить параметры RGB. Они могут принимать значения от 0 до 255. Поэтому инверсией в данном случае называется присвоение новых значений параметров RGB пикселей — из 255 вычитается текущее значение для каждого из параметров. В `applyPixelNegative` примени эффект негатива, обработав каждый пиксель, и создай новый Bitmap.
3. Добавь в MainActivity Button, при нажатии на которую при помощи `applyPixelNegative` к изображению на экране применится эффект негатива и результат отобразится на экране пользователя.

### Задание 3. Инверсия цветов Bitmap с ColorMatrix

1. Создай в файле BitmapExtensions функцию-расширение для Bitmap `applyColorMatrixNegative` с возвращаемым типом Bitmap — обработанное изображение с применением эффекта негатива (инверсия цветов).
2. Для создания эффекта негатива рассмотри, как можно обработать Bitmap при помощи [ColorMatrix](./materials/references.md#colormatrix).
3. Составь такую матрицу ColorMatrix, при применении которой в Bitmap произойдет инверсия цветов.
4. Опиши в функции `applyNegative` применение ColorMatrix для Bitmap при помощи классов Canvas и Paint:
   - Создай объект Сanvas с входным параметром пустого Bitmap с такими же размерами, как у обрабатываемого. После рисования на Canvas этот Bitmap будет содержать результат.
   - Создай объект класса Paint для рисования на Canvas и присвой ему ColorFilter на основе созданной ColorMatrix.
   - Нарисуй итоговый Bitmap на объекте Canvas при помощи его метода `drawBitmap` с входными параметрами обрабатываемого Bitmap и Paint.
5. Измени в MainActivity обработку Button из задания 2, при нажатии на которую теперь будет применяться функция `applyColorMatrixNegative` вместо `applyPixelNegative`.

### Задание 5. Применение цветового оттенка к View с AGSL

1. Создай параметр RuntimeShader на основе текста из файла [shader.txt](https://git.21-school.ru/masters/MK5_OpenGL_AndroidNDK.ID_1453077/-/blob/6/./materials/shader.txt), который описывает эффект оттенок красного.

4. Измени RuntimeShader так, чтобы применялся эффект оттенков серого вместо красного.
