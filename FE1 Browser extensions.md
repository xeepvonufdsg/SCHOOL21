## Chapter I

Перед началом изучения ознакомься с инструкцией и убедись, что у тебя установлены все необходимые инструменты для выполнения заданий.

### Что такое расширение

Наверняка ты знаешь, что такое расширение для браузера — большинство людей используют расширения в повседневной жизни для более комфортного времяпрепровождения в браузере. Как пример: AdBlock или VPN. Давай определим, что такое расширение и что оно из себя представляет.

Расширение является программой, которую можно подключить к браузеру, и главной задачей которой является расширение возможностей этого браузера.

### Как расширения работают

Расширения построены на основе веб-технологий, таких как HTML, JavaScript и CSS. Они запускаются в отдельной среде выполнения — «песочнице» — и взаимодействуют с браузером.

Расширения работают с помощью пользовательского интерфейса конечного пользователя и API разработчика.

Чтобы создать расширение, нужно собрать некоторые ресурсы: манифест, файлы JavaScript и HTML, изображения и другие, которые составляют расширение.

[Как выглядит манифест.](https://git.21-school.ru/masters/FE1_Browser_extensions.ID_1167894/-/blob/15/./materials/manifest.md).

### Canvas

Поговорим немного о таком теге, как canvas. Canvas является тегом HTML5, который предназначен для создания растрового изображения с помощью JavaScript. Забегая немного вперед, данный тег понадобится тебе для выполнения одного из заданий, поэтому будь внимательнее.

Сам `<canvas>` представляет из себя контейнер для графики. Для того чтобы что-то произошло, необходимо использовать JavaScript.

Хотелось бы затронуть тему использования изображений в canvas.

Изображения в canvas могут быть использованы для отображения фона в играх или графиках, для динамической композиции фото и так далее. Чтобы импортировать изображение в canvas для дальнейшей манипуляции нам необходимо: \
`-` Получить ссылку на HTMLImageElement или URL изображения. \
`-` Использовать метод drawImage().

CanvasRenderingContext2D предоставляет нам метод, который называется **getImageData()** — он возвращает объект ImageData, представляющий базовые пиксельные данные для указанной части холста.

### CORS

В двух словах о CORS.

**Cross-origin resource sharing (CORS)** — это механизм, основанный на HTTP протоколе, который позволяет серверу распознавать любые источники (домен, порт и т. д.), отличные от своего собственного, с которых браузер должен разрешить загрузку ресурсов. CORS также опирается на механизм, при котором перед отправкой фактического запроса браузер шлет запрос с заголовками, которые будут использоваться при фактическом запросе, на сервер, где находится cross-origin resource, для проверки возможности отправки фактического запроса.

В целях безопасности браузеры ограничивают cross-origin-запросы, инициируемые скриптами. Например, Fetch следуют same-origin-policy. Политика одинакового источника предотвращает cross-origin-атаки, блокируя доступ для прочтения загружаемых ресурсов из другого источника.

### Project\_01

Тебе предстоит реализовать два довольно полезных для frontend-разработчика расширения:

- **ColorPicker**. С помощью этого расширения юзер сможет узнать цвет любого пикселя на активной вкладке браузера.

Требования к работе расширения: \
`-` По клику на значок расширения активируется режим работы. \
`-` В режиме работы этого расширения юзер может двигать мышкой и видеть цвет каждого пикселя, на котором в текущий момент установлен курсор. \
`-` Рядом с курсором виден [label](https://git.21-school.ru/masters/FE1_Browser_extensions.ID_1167894/-/blob/15/misc/images/label.png), в котором указан цвет пикселя в форматах HEX и RGB. \
`-` При клике ЛКМ во время работы расширения в буфер обмена юзера копируется код цвета пикселя (в формате HEX), на котором установлен курсор в момент клика. \
`-` Расширение должно работать в браузере Chrome версии 108.

- **PixelRuler**. С помощью этого расширения юзер может измерить интересующую его высоту/длину.

Требования к работе расширения: \
`-` По клику на значок расширения активируется режим работы. \
`-` В режиме работы этого расширения при первом клике на любое место страницы устанавливается точка отсчета, последующий клик устанавливает финишную точку. \
`-` Между стартовой и финишной точкой строится отрезок и указывается его длина. \
`-` В режиме работы этого расширения курсор пользователя должен [измениться](https://git.21-school.ru/masters/FE1_Browser_extensions.ID_1167894/-/blob/15/misc/images/cursor.png). \
`-` Если отрезок построен, то при последующем клике появляется новая точка отсчета, а старый отрезок затирается. \
`-` Расширение должно работать в браузере Chrome версии 108.
