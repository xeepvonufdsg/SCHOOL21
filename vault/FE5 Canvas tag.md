## Chapter I

### Canvas

Canvas (тег `<canvas>`) — это HTML-элемент, который позволяет создавать растровые изображения с помощью языка программирования, в нашем случае — JavaScript. Его можно использовать для создания графов, диаграмм, изображений или текста.

Canvas API предоставляет два контекста рисования: 2D и 3D. Важно понимать, что Canvas предназначен для рисования пикселями. В нём нет фигур или векторов. Нет объектов для связывания с обработчиками событий. Это просто рисунки пикселями на экране. Сам тег `<canvas>` — это просто холст для отрисовки растровой графики. Но он предоставляет нам доступ к Canvas API и WebGL API в JavaScript. С помощью этих API ты можешь получить доступ к каждому отдельному пикселю в пределах холста и управлять его цветом в отдельности от других пикселей.

### Стили и цвета

Существует несколько свойств контекста, которые позволяют нам управлять стилями нарисованных фигур.

- `fillStyle = color` — позволяет нам установить стиль заливки для фигур. Чтобы выполнить заливку, используется команда ctx.fill().
- `strokeStyle = color` — позволяет установить цвет нарисованной линии.При этом цвет можно передавать в любом доступном формате.
- `globalAlpha` — позволяет установить значение прозрачности для всех последующих нарисованных фигур. Изображения и видео (манипуляция с пикселями — как раз отсылка к первому дню).

[Ссылка на документацию](https://developer.mozilla.org/ru/docs/Web/API/Canvas_API/Tutorial/Applying_styles_and_colors) — здесь ты найдешь еще несколько полезных функций, которые помогут тебе стилизовать твои фигуры.

### Project\_01

В этот раз от тебя требуется написать всем известную игру PAC-MAN!

- Приложение состоит из одной страницы.
- Как только страница загружается, пользователь видит поле для игры.
- Игра начинается, как только пользователь нажмет на любую клавишу управления (стрелки вверх/вниз/вправо/влево).

Напомним правила:

- Существует [поле-лабиринт](https://git.21-school.ru/masters/frontend_project05.ID_1167901/-/blob/9/misc/images/PAC_MAN_FIELD.png). При старте игры в рандомной точке данного лабиринта появляется главный герой — желтый кружок PAC-MAN. По всему лабиринту появляются золотые монеты / желтые таблетки (мы так и не нашли однозначной информации касательно того, что это такое), которые нужно съесть.
- Управлять самим персонажем можно, нажимая на стрелки.
- Персонаж двигается строго прямо, пока ты не изменишь вектор движения (нажав на нужную стрелку). Изначально можно только поворачивать направо, или налево (нельзя изменить вектор движения на диаметрально противоположный).
- Если в момент нажатия клавиши рядом находилась стена, то персонаж изменит вектор движения на ближайшем повороте.
- Также в игре присутствует 3 призрака, которые хаотично двигаются по полю.
- Если главный персонаж и призрак столкнутся, то игра закончится поражением.
- Есть нюанс, что на поле в рандомных местах генерируются 4 специальных монетки/таблетки. Съев такую, ты в течение 5 секунд съедаешь призрака при столкновении.
- Также на поле есть 2 сквозных прохода, с помощью которых можно перемещаться из одного конца поля в другой.
- Верстка должна отображаться корректно на разрешениях от 1000px до 1920px (с сохранением пропорций).
