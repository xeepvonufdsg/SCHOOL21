Сегодня мы поговорим о CSS — инструменте, без которого невозможна разработка веб-приложений.

### CSS

Наверняка многие из вас уже имеют представление о CSS, зачем он нужен и каких целей можно с его помощью достичь, но давай освежим основы и углубимся в особенности.

CSS (каскадные таблицы стилей) — это язык на основе правил: ты задаешь правила, определяющие группы стилей, которые должны применяться к определённым элементам или группам элементов на твоей веб-странице.

[Пару слов о селекторах и специфичности](https://git.21-school.ru/masters/frontend_project04.ID_1167900/-/blob/9/./materials/css_selectors.md).

### Псевдоэлементы и псевдоклассы

#### Псевдоэлементы

Псевдоэлементы — это элементы, которые мы можем создать и позиционировать, не используя HTML, а исключительно благодаря возможностям CSS. Чаще всего псевдоэлементы используются для создания оверлея, добавления иконок и других декоративных элементов.

Существует большое количество псевдоэлементов, давай рассмотрим [несколько часто встречающихся](https://git.21-school.ru/masters/frontend_project04.ID_1167900/-/blob/9/./materials/css_pseudoelements.md).

#### Псевдоклассы

Псевдоклассы — это особый вид селекторов, который позволяет добавлять стили в зависимости от состояния, например: наведение курсора, ввод невалидных данных в инпут и другие.

[Несколько часто встречающихся](https://git.21-school.ru/masters/frontend_project04.ID_1167900/-/blob/9/./materials/css_pseudoclasses.md).

### Трансформации

Свойство transform CSS позволяет поворачивать, масштабировать, изменять цвет или перемещать элемент. Оно изменяет координатное пространство модели визуального форматирования CSS. Трансформации элемента могут происходить как в 2D-представлении, так и в 3D. Чтобы использовать трансформации в CSS, есть свойство transform и функции rotate, scale, translate и др.

[Документация](https://developer.mozilla.org/en-US/docs/Web/CSS/transform).

### Анимация и переходы

#### Анимация

В CSS анимации можно создать с помощью CSS-анимаций, которые позволяют задать последовательность анимации с помощью ключевых кадров. Анимация может быть простой, состоящей из одного состояния, или даже сложной, основанной на времени.

В программах анимации, CSS и большинстве других инструментов, позволяющих анимировать что-либо, ключевые кадры (keyframes) — это механизм, который используется для назначения состояний анимации временным меткам на временной шкале.

[Пример css @keyframes](https://git.21-school.ru/masters/frontend_project04.ID_1167900/-/blob/9/./materials/css_keyframes.md).

#### Переходы

Наверняка ты замечал, что многие элементы веб-приложений, как правило, имеют состояния, например, кнопки, меняющие цвет при наведении, выпадающие списки или чекбоксы. По умолчанию, например, с использованием псевдоклассов, CSS моментально меняет свойства элементов. При помощи переходов мы можем сделать данный процесс плавным и более user-friendly. Чтобы использовать переходы, в CSS есть свойство transition.

[Документация](https://developer.mozilla.org/en-US/docs/Web/CSS/transition).

### СSS-архитектура

Существуют различные методики для организации CSS-кода. Если хочешь углубиться в эту тему, то советуем изучить:

- БЭМ-методику;
- CSS modules;
- OOCSS.

Данные методики носят рекомендательный характер. Как правило, для более эффективной разработки в команде используется единая стилистика написания и организации кода.

### Препроцессоры

Препроцессоры CSS — это скриптовые языки, расширяющие собственные возможности CSS. Благодаря им мы можем использовать логику в нашем CSS-коде, т. е. переменные, вложенность, наследование, mixins, функции и математические операции. Среди самых популярных препроцессоров можно назвать SASS, LESS, STYLUS и POSTCSS.

### Project\_01

Сегодня тебе потребуется разработать онлайн железную дорогу! \
Приложение состоит всего из одной страницы.

- На главной странице пользователь видит застывший поезд, который не двигается по железной дороге, и кнопку Start.
- При клике на кнопку поезд приходит в движение и едет без остановок.
- Сама ЖД дорога представляет собой две закольцованные железные дороги, соединенные между собой стрелкой.
- Изначально поезд двигается только по одной кольцевой дороге, но при клике на стрелку происходит ее переключение, и поезд начинает двигаться по обеим железным дорогам, рисуя восьмерку.
- При переключении стрелки поезд заканчивает движение по одному кольцу до стрелки, после чего перемещается на соседнее кольцо и двигается по нему. При следующем клике по стрелке поезд снова заканчивает движение по текущему кольцу, после чего перемещается.
- Ограничений на реализацию анимаций нет. Можно использовать как JS, так и CSS.
- Верстка должна отображаться корректно на разрешениях от 1000px до 1920px (с сохранением пропорций).
