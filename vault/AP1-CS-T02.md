## Задание 1. Многообразие транспортных средств

Разработай модуль, который выводит список транспортных средств и информацию о каждом средстве.

- Программа работает с ссылочными типами данных.

**Создание классов и переопределение методов**

- Создай абстрактный класс Vehicle с двумя закрытыми полями: String type, Double speed.
- Класс Vehicle должен быть в отдельном файле.
- В классе Vehicle создай абстрактный метод String intelligence().
- Создай класс Car, который наследуется от класса Vehicle.
- Переопредели метод intelligence() в классе Car, чтобы сведения о транспортном средстве выводились в таком виде: «Type car = [тип автомобиля], speed = [скорость транспортного средства]».
- Класс Car должен быть в отдельном файле.
- Создай класс Plane, который наследуется от класса Vehicle.
- Переопредели метод intelligence() в классе Plane, чтобы сведения о транспортном средстве выводились в таком виде: «Type plane = [тип самолета], speed = [скорость транспортного средства]».
- Класс Plane должен быть в отдельном файле.

**Считывание входных данных для программы**

- Программа считывает количество транспортных средств.
- Программа считывает тип вводимого транспортного средства: car/plane.
- Затем программа считывает тип транспортного средства и скорость.
- Каждое транспортное средство добавляется в общий список transports.

**Проверки для входных данных**

- Если ввели неправильный тип транспортного средства, то программа выводит: «Incorrect input. Unsupported vehicle type» и переходит к следующему вводу.
- Если ввели отрицательную скорость, то программа выводит: «Incorrect input. Speed < 0» и переходит к следующему вводу.
- Программа не завершается с ошибкой при некорректных входных данных. Она выводит: «Could not parse a number. Please, try again» и повторяет попытку ввода.

**Вывод данных**

- Программа должна вывести информацию о каждом транспортном средстве.

| Входные данные | Выходные данные |
| --- | --- |
| 3  plane  cargo  780  car  passenger  100  car  truck  60 | Type plane = cargo, speed = 780  Type car = passenger, speed = 100  Type car = truck, speed = 60 |
| 3  train  car  truck  -41  plane  passenger  500 | Incorrect input. Unsupported vehicle type  Incorrect input. Speed < 0  Type plane = passenger, speed = 500 |
| 2  car  passenger  90  plane  cargo  800 | Type car = passenger, speed = 90  Type plane = cargo, speed = 800 |

## Задание 2. Расход топлива на 100 км

Разработай модуль, который выводит расход топлива на 100 км каждого транспортного средства.

- Используй функционал из предыдущего задания с некоторыми дополнениями.
- Добавь к классу Vehicle закрытое поле Integer tankVolume.
- Объяви в классе Vehicle метод Float getFuelConsumL().
- Реализуй метод getFuelConsumL() в классе Car, который вычисляет количество необходимого топлива на 100 км пути по следующей формуле: `расход топлива = объем бака / пройденный путь в км * 100`.
- Переопредели метод intelligence() в классе Car, чтобы сведения о транспортном средстве выводились в таком виде: «Type car = [тип автомобиля], speed = [скорость транспортного средства], tankVolume = [объем бака], fuelConsum = [расход топлива]».

## Задание 5. Победитель

Разработай модуль, который выводит информацию о каждом транспортном средстве, а также указывает победителя гонки и время, потраченное на гонку, у каждого транспортного средства.

**Создание классов и переопределение методов**

- Используй функционал 1 задания (класс Car).
- Используй класс Bike из 3 задания.
- В классе Vehicle объяви метод Double timeRace().
- Переопредели метод timeRace() в классе Car следующим образом: метод вычисляет время, затраченное на гонку, в секундах.
- Переопредели метод intelligence() в классе Bike, чтобы сведения о транспортном средстве выводились в таком виде: «Type bike = [тип мотоцикла], speed = [скорость транспортного средства]».
- Переопредели метод timeRace() в классе Bike следующим образом: метод вычисляет в секундах время, затраченное на гонку.
- Вычисление времени прогулки для класса Car выполняй по следующей формуле: `[время_гонки] = [длина трассы] / [скорость_транспортного_средства в м/с] * 1.07`.
- Вычисление времени прогулки для класса Bike выполняй по следующей формуле: `[время_гонки] = [длина трассы] / [скорость_транспортного_средства в м/с]`.

**Считывание входных данных для программы**

- Программа считывает количество транспортных средств.
- Программа считывает длину гоночной трассы в метрах.
- Программа считывает тип вводимого транспортного средства: car/ bike.
- Затем программа считывает вид транспортного средства и скорость.
- Каждое транспортное средство добавляется в общий список transports.

**Проверки для входных данных**

- Если в transports будет меньше 2 транспортных средств, то программа выводит: «No one to compete with».
- Если ввели отрицательную или нулевую длину гоночной трассы, то программа выводит: «Incorrect input. Distance < 0» и переходит к следующему вводу.
- Если ввели неправильный тип транспортного средства, то программа выводит: «Incorrect input. Unsupported vehicle type» и переходит к следующему вводу.
- Если ввели отрицательную скорость, то программа выводит: «Incorrect input. Speed < 0» и переходит к следующему вводу.
- Программа не завершается с ошибкой при некорректных входных данных. Она выводит: «Could not parse a number. Please, try again» и повторяет попытку ввода.

**Выполнение задания**

- Программа должна вызвать метод timeRace() у каждого транспортного средства.
- Транспортные средства стартуют одновременно, поэтому каждый вызов метода timeRace() выполняется параллельно в отдельном потоке.
- Программа ждет выполнение всех вызовов метода timeRace(), перед тем как завершиться.

**Вывод данных**

- По завершении гонки программа должна выводить на одной строке в консоль следующую информацию: сведения о транспортном средстве и время, потраченное на гонку.
- После завершения всех параллельных потоков программа выводит информацию о победителе.

**Требования**

- Точность: 3 знака после запятой.
- Программа работает со ссылочными типами данных.
- В программе необходимо использовать параллельное программирование, о котором можно узнать из материалов к этому уроку.
