## Chapter I

### Необходимость в визуализации информации

Время от времени встает необходимость отобразить сложные данные в приложении. Под сложными данными будем подразумевать данные, которые тяжело воспринимать каким-то простым способом (текстом, списком или таблицей). Поэтому для визуального восприятия различной информации мы используем определённые типы графиков.

Примеры эффективного восприятия информации:

- Если нужно узнать, как цифры ведут себя в течение какого-то временного периода, то стоит выбрать линейные или столбчатые диаграммы.
- Для акцента на соотношение значения лучше использовать круговые диаграммы.
- Если нужно понять, как одни показатели влияют на другие, то можно использовать смешанные виды графиков на одной оси.

### D3

D3.js — это JavaScript-библиотека для обработки и визуализации данных. Она состоит из нескольких десятков небольших [модулей](https://github.com/d3), каждый из которых решает свою задачу. Кроме модулей для построения различных фигур, внутри D3 есть модули для работы с элементами на странице (простой аналог jQuery), загрузкой данных (аналог fetch/$.ajax, заточенный под форматы csv, json, xml и другие), форматированием и масштабированием данных, математическими функциями и другим.

[Примеры](https://git.21-school.ru/masters/frontend_project08.ID_1167906/-/blob/9/./materials/d3_examples.md)

### Chart.js

Chart.js — библиотека JavaScript для создания диаграмм. Chart.js предоставляет готовые столбчатые, линейные, круговые и диаграммы рассеяния. Для создания диаграммы требуется минимальное количество кодирования и времени. Диаграммы также включают легенду, всплывающее окно при наведении и переключение серий. Они также реагируют на размер устройства.

Диаграммы можно настраивать. Например, легенда может отображаться над, под или сбоку от графика. Внешний вид графика также можно изменить, изменив цвет фона, цвет линий, ширину линий и многое другое.

Chart.js отображает свои графики с помощью элемента Canvas, что обеспечивает высокую производительность по сравнению с SVG, особенно при отображении большого количества данных. Другим преимуществом рендеринга Canvas является то, что график относительно легко загрузить в виде файла изображения.

[Примеры](https://git.21-school.ru/masters/frontend_project08.ID_1167906/-/blob/9/./materials/charts_js_examples.md)

### Сравнение

Сравнительная таблица:

| Критерий | D3 | Chart.js |
| --- | --- | --- |
| Структура визуализации | Строительные блоки для построения визуализаций данных | Готовые диаграммы |
| Настройка визуализации | Состав строительных блоков | Конфигурация |
| Технологии отрисовки | SVG или Canvas | Canvas |
| Интерактивность | Интерактивность требует кодирования | Интерактивность (всплывающие подсказки, выбор серии) по умолчанию |
| Отзывчивость | Отзывчивость требует кодирования | Отзывчивость по умолчанию |
| Легенда | Легенда требует кодирования | Легенда по умолчанию |

В заключении можно сказать, что D3 является более тяжелой для освоения библиотекой, но более подходящей для построения индивидуальной визуализации с множеством параметров, в то время как Chart.js покрывает большую часть стандартных задач с помощью своих стандартных диаграмм.

### Project\_01

- В данном проекте от тебя потребуется реализовать платформу для трейдинга.
- После авторизации/регистрации пользователь попадает на главную страницу, где может посмотреть список торговых пар с текущим курсом.
- Пользователь может менять местами элементы списка для вывода вверх более актуальных для себя пар.
- Курс указывается в режиме реального времени ([API для получения данных](https://www.alphavantage.co/documentation/)).
- При клике на какую-либо торговую пару пользователь видит перед собой график, который меняется в режиме реального времени.
- Изначально график представляет из себя стандартную ломанную, но пользователь может изменить вид на так называемые «свечи».
- На графике можно также посмотреть данные за день/неделю/месяц.
- Верстка должна выглядеть корректно на разрешениях от 1000px до 1920px.
