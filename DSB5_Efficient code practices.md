## Глава I

### Предисловие

Есть два английских термина, которые часто путают: *efficiency* и *effectiveness*.

Проще всего различать их так:

- Результативность (*effectiveness*) — делать правильные вещи: те, что ведут к намеченной цели.
- Эффективность (*efficiency*) — делать вещи правильно: с разумными затратами времени и ресурсов.

Или, как сказал Питер Друкер:
«*Efficiency* — это делать вещи правильно; *effectiveness* — делать правильные вещи».

Твой код должен быть и результативным, и эффективным.

## Глава IV

### Упражнение 00. Списковое включение (list comprehensions)

- Каталог для сдачи: `ex00/`.
- Файлы для сдачи: `benchmark.py`.
- Разрешённые импорты: `import timeit`.

Представь, что тебе нужно найти все адреса Gmail в списке адресов электронной почты. Обычный подход — написать цикл, пройтись по исходному списку и добавлять подходящие значения в новый список.

Однако при больших объёмах данных этот метод может быть неэффективным. Более эффективный и «питоничный» способ — использовать списковые включения (list comprehensions).

В этом упражнении тебе нужно:

1. Написать две функции:
   - В первой реализовать обычный подход с циклом и `append`.
   - Во второй — использовать списковое включение.
2. Использовать `timeit`, чтобы измерить время выполнения этих функций 90 000 000 раз и сравнить результаты.
3. Оформить это в скрипт, который печатает: «It is better to use a list comprehension», если время для спискового включения меньше либо равно времени для цикла, и «It is better to use a loop» — в обратном случае.
4. Также добавь численные значения времени сразу после указанной строки. Упорядочь их от меньшего к большему.

Используй следующий список адресов:

```
emails = [’john@gmail.com’, ’james@gmail.com’, ’alice@yahoo.com’, 
’anna@live.com’, ’philipp@gmail.com’]
```

1. Продублируй каждое значение пять раз. В итоге список будет содержать 25 элементов, из которых 5 — уникальные.

Пример:

```
$ ./benchmark.py
it is better to use a list comprehension
55.71611063099999 vs 58.849982983
```

### Упражнение 01. Map

- Каталог для сдачи: `ex01/`.
- Файлы для сдачи: `benchmark.py`.
- Разрешённые импорты: `import timeit`.

Ты, вероятно, заметил разницу: списковые включения немного эффективнее и читабельнее циклов. Но это не единственный вариант — есть ещё `map()`!

`map` пришёл из функционального программирования. С `map` не нужно явно итерироваться по списку: ты применяешь функцию к итерируемому объекту. Этим и займёмся.

Модифицируй скрипт из предыдущего упражнения:

1. Напиши функцию, которая делает то же самое — формирует список Gmail-адресов из исходного списка из 25 e-mail’ов — но с использованием `map`. Попробуй и `map()`, и `list(map())`. Обрати внимание на разницу в скорости.
2. По-прежнему нужно сравнить, какая функция работает быстрее. Теперь у тебя три варианта: цикл, списковое включение и `map`. Добавь ещё одну фразу в вывод: «It is better to use a map». В конце выведи все три значения времени в порядке возрастания.

Пример:

```
$ ./benchmark.py
it is better to use a map
29.32016281 vs 54.620376492999995 vs 55.99120069
```

## Глава VI

### Упражнение 02. Filter

- Каталог для сдачи: `ex02/`.
- Файлы для сдачи: `benchmark.py`.
- Разрешённые импорты: `import timeit`, `import sys`.

Заметил, что в предыдущих упражнениях ты по сути выполнял фильтрацию? Почему бы не использовать для этого соответствующую функцию `filter()` вместо списковых включений и `map`? Работает почти так же, как `map()`. Уверен, тебе это зайдёт!

Добавь в бенчмарк новую функцию, которая использует `filter()`. На этот раз немного изменим код структурно: создай скрипт, который принимает название функции (`loop`, `list_comprehension`, `map` или `filter`) и число вызовов для бенчмарка. В ответ скрипт должен выводить время, за которое выполняется указанное количество вызовов выбранной функции.

Примеры:

```
$ ./benchmark.py loop 10000000
6.230267604
$ ./benchmark.py list_comprehension 10000000
6.214286791
$ ./benchmark.py map 10000000
3.063598874
$ ./benchmark.py
```

## Глава VII

### Упражнение 03. Reduce

- Каталог для сдачи: `ex03/`.
- Файлы для сдачи: `benchmark.py`.
- Разрешённые импорты: `import timeit`, `import sys`, `from functools import reduce`.

Помимо `map()` и `filter()` есть ещё одна полезная функция — `reduce()`. Её можно использовать вместо циклов; как правило, она эффективнее при вычислении сумм. В этом упражнении нужно вычислить сумму квадратов до заданного аргумента. Например, для 5 это: `1 + 4 + 9 + 16 + 25 = 55`.

1. В скрипте создай две функции:
   - В первой реализуй обычный подход с циклом и выражением `sum = sum + i*i`.
   - Во второй используй `reduce()`.
2. Создай скрипт, который принимает: название функции (`loop` или `reduce`), число вызовов для бенчмарка и число N для подсчёта суммы квадратов. В ответ скрипт должен выводить время, за которое выполняется указанное количество вызовов выбранной функции.

Пример:

```
$ ./benchmark.py loop 10000000 5
6.230267604
$ ./benchmark.py reduce 10000000 5
3.063598874
```

4. Выполни пункты 2 и 3 с использованием `Counter`.

## Глава IX

### Упражнение 05. Генератор (generator)

- Каталог для сдачи: `ex05/`.
- Файлы для сдачи: `ordinary.py`, `generator.py`.
- Разрешённые импорты: для Linux/macOS — `import sys`, `import resource`; для Windows — `import sys`, `import os`, `import psutil`.

Эффективность кода определяется не только скоростью его исполнения, но и потреблением оперативной памяти. Это особенно важно при работе с большими данными. Но и данные меньших объёмов могут создавать проблемы. Давай проведём ещё один эксперимент.

1. Скачай [набор данных MovieLens](https://files.grouplens.org/datasets/movielens/ml-25m.zip).
2. Распакуй его. Тебе понадобится файл `ratings.csv` (678,3 MB — не так уж много, правда?).
3. Создай первый скрипт `ordinary.py`. В нём должна быть ровно одна функция: чтение всех строк файла в список и возврат этого списка. В основной программе напиши цикл, который итерируется по списку и вызывает `pass`. Путь к файлу передавай скрипту аргументом.
4. Создай второй скрипт `generator.py`. Этот скрипт делает то же самое, но твоя функция должна использовать генератор. Ключевое слово `yield` читает по одной строке за раз и возвращает её вызывающей стороне. В основной программе напиши цикл, который итерируется по генератору и вызывает `pass`. Путь к файлу передавай скрипту аргументом.
5. Оба скрипта должны выводить `Peak Memory Usage` в гигабайтах и `User Mode Time + System Mode Time` в секундах. Если у тебя Windows, используй соответствующие функции, чтобы получить те же метрики.

Пример:

```
$ ./ordinary.py ratings.csv
Peak Memory Usage = 2.114 GB
User Mode Time + System Mode Time = 5.77s
$ ./generator.py ratings.csv
Peak Memory Usage = 0.005 GB
User Mode Time + System Mode Time = 9.04s
```
